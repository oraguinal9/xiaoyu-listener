# 小语 · AI 情感树洞

AI 情感陪伴/树洞应用「小语」的站点构建产物（Next.js static export）。

> ▶ 在线体验：https://yuyan.zbjh.top

## 说明

- 本仓为**构建产物**（源码未随仓分发），任意静态服务器即可预览：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```

- `models.json` 声明 Live2D 模型清单；VRM 模型文件（约 278M）因体积与授权原因**不随仓库分发**，放入 `models/` 目录即可运行。
